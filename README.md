# 🤖 Jarvis Local

Um assistente de IA local desenvolvido em Python usando Ollama.

O objetivo do projeto é criar um assistente pessoal capaz de conversar, guardar memória e executar algumas tarefas no computador.

## 🚀 Recursos

* 🧠 IA local com Ollama
* 💾 Sistema de memória
* 🛠️ Ferramentas para executar tarefas
* 🔍 Análise de código
* 🔐 Análise básica de segurança
* 📋 Sistema de planejamento
* 🔄 Sistema de reflexão e tentativa novamente
* 💻 Interface gráfica flutuante

## 🧰 Tecnologias

* Python
* Ollama
* Qwen 2.5
* PySide6

## ▶️ Como executar

Instale as dependências:

```bash
pip install ollama PySide6 rich
```

Baixe o modelo:

```bash
ollama pull qwen2.5:3b
```

Execute:

```bash
python main.py
```

Ou abra a interface gráfica:

```bash
python main_gui.py
```
